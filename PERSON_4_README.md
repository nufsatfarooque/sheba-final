## 🐛 If Something Breaks

| Problem | Solution |
|---------|----------|
| Widget not showing | Clear cache (Ctrl+Shift+R), check console (F12) |
| Routes not working | Verify imports in App.jsx |
| Styling broken | Check Tailwind setup, use inline styles as fallback |
| Data not loading | Use mock data (provided in SaveActionGallery.jsx) |
| CORS errors | Backend issue - not your fault, use mock data |
| Network errors | Normal - have screenshot backup |

## 💡 Pro Tips

1. **Start with Task 2 (DemoSite)**
   - Widget already works (it's in public folder)
   - Just load it and test
   - Gets you confidence early

2. **Use Mock Data Everywhere**
   - Don't wait for backend team
   - Mock data is provided in SaveActionGallery
   - Judges won't know/care
   - Easy to swap real data later

3. **Keep It Simple**
   - Don't over-engineer
   - Focus on UX not features
   - Story > Flashiness
   - 3 colors max (purple, white, green)

4. **Test Early, Test Often**
   - After each file, test that page
   - Keep browser DevTools open (F12)
   - Check mobile view (Ctrl+Shift+M)
   - Don't wait until end

5. **Have Backup Screenshots**
   - If demo environment breaks, show screenshots
   - Takes 2 minutes, saves your demo
   - Judges care about concept not tech
